## 修正

1. 正式同步與後台預覽均先對照已收錄且未結束的來源資料。矛盾的零筆結果重試一次；仍為零則該來源失敗，整次執行為 partial 或 failed。保留既有活動，其他來源照常處理。沒有已知未結束活動的來源可合法回傳零筆。
2. 紀錄每個來源的 rawCount（全國／年曆原始筆數）、fetched（篩出宜蘭筆數）、fetchedAt、attempts 及 contentHash，請求要求不使用快取。後台顯示原始與宜蘭筆數，部分失敗不再顯示綠色成功提示。
3. finished_at 改用 PostgreSQL clock_timestamp()，避免 transaction 的 now() 讓開始與結束時間完全相同。
