# Mobile navigation icons

`mobile-tabs.json` bundles the ten Remix Icon SVG paths used by
`components/MobileTabBar.vue` (24 × 24 viewBox, original `currentColor` paths).
Both the outlined and filled states are included so navigation never needs a
runtime Iconify request. Keep both states in sync with `utils/site-nav.js`.

Source: https://api.iconify.design/ri.json (retrieved 2026-10-31).
Collection metadata: https://github.com/iconify/icon-sets/blob/master/json/ri.json
(Remix Icon 4.8.0, Remix Design, Apache-2.0).
The original license is included in `LICENSE-remixicon.txt`.
